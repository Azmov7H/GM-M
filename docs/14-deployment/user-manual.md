# دليل المستخدم

دليل تشغيل نظام alli-jamm للمخزون ونقطة البيع (للموظفين وأصحاب المحلات).

## 1. تسجيل الدخول

1. افتح المتصفح على عنوان النظام (مثال: `http://localhost:3000/login`).
2. أدخل اسم المستخدم وكلمة المرور ثم اضغط **تسجيل الدخول**.
3. بعد 5 محاولات فاشلة يُقفل الدخول لمدة 15 دقيقة — انتظر ثم حاول مجدداً.
4. لتسجيل الخروج استخدم زر الخروج في القائمة الجانبية.

> غيّر كلمة المرور الافتراضية (`admin123`) فور أول دخول من صفحة
> النظام → المستخدمون.

## 2. الرئيسية (لوحة المتابعة)

تعرض ملخص اليوم: إجمالي المبيعات، الربح، الفواتير، تنبيهات النواقص،
وأحدث الحركات. استخدم فلتر التاريخ أعلى الصفحة لعرض فترات سابقة.

## 3. نقطة البيع (المبيعات → نقطة البيع)

1. اختر **المخزن** (الرئيسي أو المحل) و**العميل** (عميل نقدي للبيع الفوري).
2. ابحث برقم الصنف أو الاسم — اضغط `F2` للانتقال السريع إلى البحث.
3. أضف الأصناف بالكميات المطلوبة؛ عدّل الكمية أو احذف سطراً عند الحاجة.
4. اختر طريقة الدفع: **نقدي** أو **آجل** (الآجل يسجّل ديناً على العميل).
5. اضغط **إتمام البيع** — تُطبع/تُعرض الفاتورة ويُخصم المخزون تلقائياً.
6. لا يمكن إتمام بيع بسلّة فارغة، ولا بيع كمية غير متوفرة (يظهر تنبيه نقص).

### سجل الفواتير

يعرض كل الفواتير مع البحث والفلترة. افتح أي فاتورة لعرض تفاصيلها وطباعتها.

### مرتجع المبيعات (صفحة مستقلة)

صفحة المبيعات → مرتجع المبيعات تعرض الفواتير المكتملة: اختر فاتورة، حدد
الكميات المرتجعة لكل صنف (بحد أقصى الكمية غير المرتجعة)، أدخل السبب وأكّد.

## 4. المخزون

### المنتجات

إضافة منتج جديد: الاسم، رقم الصنف (SKU)، الفئة، الوحدة، سعر الشراء وسعر البيع،
وحدّ إعادة الطلب. يمكن تعديل الأسعار لاحقاً — يُحفظ سجل الأسعار القديمة.

### المخزون الحالي

رصيد كل صنف في كل مخزن. اللون الأحمر يعني أن الرصيد وصل حدّ إعادة الطلب.

### حركات المخزون

سجل لا يُحذف لكل دخول وخروج: مشتريات، مبيعات، تحويلات، تسويات، جرد، مرتجعات.

### الجرد الفعلي

1. أنشئ عملية جرد وحدد المخزن.
2. أدخل الكميات المعدودة فعلياً لكل صنف.
3. اعتمد الجرد — تُنشأ حركات تسوية بالفروقات تلقائياً.

### نقل المخزون بين المخازن

حدد الصنف والكمية والمخزن المصدر والوجهة. النقل ذرّي: لا يتم إلا بتوفر الرصيد.

## 5. المشتريات (المخزون → أوامر الشراء)

1. أنشئ أمر شراء واختر **المورد** والأصناف والكميات وأسعار الشراء.
2. عند وصول البضاعة اضغط **استلام** — يدخل المخزون إلى المخزن الرئيسي
   ويُحدَّث متوسط سعر الشراء.
3. الشراء الآجل يسجّل ديناً على المحل لصالح المورد.

## 6. العملاء والموردون

- بطاقة كل عميل/مورد تعرض: البيانات، الرصيد الحالي، الفواتير، والمدفوعات.
- **تسجيل دفعة:** من البطاقة أدخل المبلغ — يُخفّض الدين. لا يمكن دفع أكثر
  من الرصيد المستحق.
- لا يمكن تعطيل عميل/مورد ما دام عليه رصيد.
- صفحة **الديون** (المالية → الديون) تجمع كل الأرصدة المستحقة في مكان واحد.

## 7. التقارير

| التقرير          | ماذا يعرض                        |
| ---------------- | -------------------------------- |
| تقرير المبيعات   | الفواتير والإجماليات لفترة محددة |
| التقارير المالية | الإيراد والمصروف وصافي الربح     |
| ربحية العملاء    | ربح كل عميل (بسعر الشراء الحالي) |
| سجل الأسعار      | تاريخ تغيّر أسعار الأصناف        |
| النواقص          | الأصناف تحت حدّ إعادة الطلب      |

كل تقرير يدعم فلتر التاريخ والتصدير إلى CSV.

## 8. النظام

### الخزينة والإغلاق اليومي

صفحة المالية → الخزينة تعرض ملخص اليوم: عدد الفواتير، المبيعات النقدية
والآجلة، التحصيل من العملاء، المدفوع للموردين، المرتجعات، و**النقد المتوقع
في الدرج** — قارنه بالنقد الفعلي نهاية اليوم.

### تخصيص الشركة والفواتير

من النظام → الإعدادات → **الشركة والفواتير** (للمدير فقط):

- اسم الشركة والهاتف والعنوان — تظهر في الشريط الجانبي وأعلى كل فاتورة.
- قالب الفاتورة: قياسي أو مدمج؛ مقاس الورق: A4 أو طابعة حرارية 80مم.
- إظهار/إخفاء: العميل، طريقة الدفع، البائع.
- تذييل الفاتورة (مثال: شكراً لتسوقكم معنا).
- خيار السماح بالبيع بأقل من سعر التكلفة (مغلق افتراضياً).

### المستخدمون والأدوار

- أنشئ مستخدماً لكل موظف مع الدور المناسب (مدير / كاشير / أمين مخزن / مشاهد).
- الصلاحيات تتحكم بما يراه كل دور — الكاشير مثلاً لا يصل إلى الإعدادات.
- يمكن إعادة تعيين كلمة مرور أي موظف، وتعطيل حسابه عند المغادرة
  (لا يمكن تعطيل آخر مدير).

### الإعدادات والنسخ الاحتياطي

- **إنشاء نسخة احتياطية** (3 مرات بالساعة كحد أقصى) ثم **تنزيلها** وحفظها
  خارج الجهاز.
- **الاستعادة** تستبدل كل البيانات الحالية — تُؤخذ نسخة أمان تلقائياً أولاً
  وتتطلب تأكيداً كتابياً، وتُسجّل خروج جميع المستخدمين.

## 9. نصائح يومية

1. ابدأ اليوم بمراجعة النواقص في الرئيسية.
2. سجّل كل المبيعات لحظياً من نقطة البيع.
3. طابق الخزينة (المالية → الخزينة) مع النقد الفعلي نهاية اليوم.
4. خذ نسخة احتياطية يومياً واحتفظ بها خارج الجهاز.
